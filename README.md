# Patrion

Aplicación de finanzas personales desarrollada en Kotlin para gestionar cuentas, ingresos, gastos y ahorros, con seguimiento del 4×1000 y una visión contable basada en partida doble.

## Tecnologías

- Kotlin
- Jetpack Compose
- Room / SQLite
- Android API 26+ (Android 8.0+)

## Funcionalidades

- Gestión de cuentas y saldos.
- Registro de ingresos, gastos y transferencias.
- Seguimiento del 4×1000 cuando corresponda.
- Categorías personalizadas.
- Consulta de movimientos y balances financieros.
